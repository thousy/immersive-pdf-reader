# 沉浸式 PDF 阅读系统 (Immersive PDF Reader)

一个基于 `PDF.js` 和 Python `http.server` 构建的轻量级、沉浸式 PDF 阅读与学习系统。专为需要高效阅读、背诵、复习 PDF 资料（如考试冲刺资料、默写本等）的用户设计。

## 🌟 特色功能

- 📂 **智能文档导航**：自动扫描并列出运行目录下的所有 PDF 文件，支持置顶核心学习资料。
- 🌓 **深色/浅色护眼模式**：支持一键切换主题，深色模式下对 PDF 页面进行智能反色处理，深夜学习不伤眼。
- 💾 **阅读进度记忆**：基于 `localStorage` 自动记录并保存每份文档的最后阅读页码，再次打开自动续读。
- ⚡ **极致流畅体验**：基于毛玻璃（Glassmorphism）现代设计美学，支持键盘左右方向键 (`←` / `→`) 快捷翻页，支持平滑缩放。
- 🛠️ **零依赖部署**：除 Python 自带标准库外无任何第三方依赖（除提取测试脚本外），开箱即用。

## 🚀 快速开始

### 1. 准备工作
将你需要阅读的 `.pdf` 文件放入本项目的根目录下。

### 2. 启动服务
在项目根目录下，运行 Python 服务端程序：
```bash
python server.py
```

### 3. 开始阅读
打开浏览器，访问以下地址即可开始沉浸式阅读：
👉 **[http://localhost:8080](http://localhost:8080)**

## ⌨️ 快捷键

- `→` 或 `PageDown`：下一页
- `←` 或 `PageUp`：上一页

## 🛠️ 项目结构

```text
├── server.py         # Python 极简 Web 服务器（处理 API 及静态资源分发）
├── web/              # 前端网页资源
│   ├── index.html    # 阅读器主页面
│   ├── style.css     # 现代毛玻璃样式表
│   └── app.js        # PDF.js 渲染与核心交互逻辑
└── README.md         # 项目说明文档
```
